# Compras da Casa — Validação

Página estática para a família revisar a lista de compras: aprovar itens, ajustar quantidades e periodicidade, avaliar preços (caro/justo/barato), sugerir itens novos e enviar o feedback por WhatsApp.

- 100% no navegador, sem servidor — o rascunho fica salvo no aparelho (localStorage).
- A senha da página é uma camada leve de privacidade (client-side), não segurança forte.
- Parte de um projeto pessoal de automação doméstica.
